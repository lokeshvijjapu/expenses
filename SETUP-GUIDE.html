📲 My Expenses: setup guide

You only do this once, on your laptop. It takes about 20 minutes. Everything is free and no credit card is needed.

What you're setting up:
• Firebase (by Google) is the database where your expenses are safely stored.
• GitHub Pages gives you a free website link for the app, which you open on your phone and laptop.

1Unzip the files

Right-click the expenses-app.zip file → Extract All. You'll get a folder with these files:
index.html firebase-config.js sw.js manifest.json icon-192.png icon-512.png apple-touch-icon.png firestore-rules.txt

2Create a Firebase project

  1. Go to console.firebase.google.com and sign in with your Google (Gmail) account.
  2. Click Create a project (or "Get started").
  3. Name it my-expenses → Continue.
  4. When it asks about Google Analytics, turn it off (you don't need it) → Create project.

3Connect the app to Firebase

  1. On the project home page, click the Web icon </> ("Add app" → Web).
  2. App nickname: expenses. Don't tick "Firebase Hosting". Click Register app.
  3. Firebase shows some code with const firebaseConfig = { apiKey: "...", ... }.
  4. Open firebase-config.js from your folder with Notepad (right-click → Open with → Notepad).
  5. Replace each "PASTE_HERE" with the matching value from Firebase. It should end up looking like this (with your own values): 
    export const firebaseConfig = {
  apiKey: "AIzaSyB....",
  authDomain: "my-expenses-1234.firebaseapp.com",
  projectId: "my-expenses-1234",
  storageBucket: "my-expenses-1234.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abc123"
};
  6. Save the file (Ctrl+S).

These values are not secret passwords. They just tell the app which database is yours. Your data is protected by your login and the rules in step 5.

4Turn on email login

  1. In the left menu: Build → Authentication → Get started.
  2. Go to the Sign-in method tab → click Email/Password → turn on the first switch (Enable) → Save.

5Create the database

  1. Left menu: Build → Firestore Database → Create database.
  2. Location: choose asia-south1 (Mumbai). You can't change this later.
  3. Choose Start in production mode → Create.
  4. Open the Rules tab. Delete everything in the box, paste the text from firestore-rules.txt, and click Publish.

These rules mean only you (after logging in) can read or change your expenses.

6Put the app online with GitHub Pages

  1. Go to github.com and Sign up (free). Remember your username.
  2. Click + (top right) → New repository. Name: expenses. Keep it Public. Click Create repository.
  3. On the next page, click the link "uploading an existing file".
  4. Drag all the files from your folder into the page (you can skip SETUP-GUIDE.html) → click Commit changes.
  5. Go to the repository's Settings → Pages (left menu).
  6. Under "Build and deployment", Source: Deploy from a branch, Branch: main, folder / (root) → Save.
  7. Wait 1–2 minutes and refresh. Your app link appears at the top:
    https://YOUR-USERNAME.github.io/expenses/

7Allow your link in Firebase

  1. Back in Firebase: Authentication → Settings → Authorized domains → Add domain.
  2. Type YOUR-USERNAME.github.io (without https:// and without /expenses) → Add.

8Start using it 🎉

  1. Open your link on the laptop → tap Create new account → enter your email and a password.
  2. On your phone, open the same link in Chrome → Sign in with the same email and password.
  3. To install it like an app: Chrome menu ⋮ → Add to Home screen / Install app. (iPhone: Safari → Share → Add to Home Screen.)

Optional but recommended: after you've created your account, stop strangers from making accounts: Firebase → Authentication → Settings → User actions → untick Enable create (sign-up) → Save.

🔒 Keeping your data safe

  • Your data is stored in Google's Firebase servers, so it's not lost if your phone breaks or you clear the browser.
  • The app also keeps a copy on your phone, so you can add expenses without internet. They sync automatically when you're back online.
  • For extra safety, once a month go to Settings → Download backup and keep that file (e.g. in Google Drive).
  • Don't forget your password. If you do, use "Forgot password?" on the login screen.

The free Firebase plan allows 50,000 reads and 20,000 saves per day. Personal use is far below that, so you'll never pay anything.

✏️ Changing the app later

If you get an updated index.html, open your GitHub repository → Add file → Upload files → drop the new file → Commit changes. The app updates within a couple of minutes, and your data stays exactly as it is.
